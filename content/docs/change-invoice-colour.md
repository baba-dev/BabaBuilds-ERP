# How to Change Your Invoice Colour

You can set one brand colour for every invoice, and override it for a client or a single invoice.

<HelpImage src="/help/diagrams/invoice_accent_chain.svg" alt="The invoice colour is taken from the invoice first, then the client, then the workspace, then the design" caption="The first level with a colour set wins." width={960} height={360} />

## For every invoice

1. Open **Settings → Invoicing**.
2. Under **Accent colour**, pick a swatch, use the colour wheel, or type a hex code such as `#0F766E`.
3. Select **Save**.

## For one client

Open the client, set **Invoice colour for this client**, and save. Every future invoice to that client uses it.

## For one invoice

In the new invoice form, set **Invoice colour**. It overrides the client and workspace colours for that invoice only.

## If a colour is too light

Very light colours are hard to read on paper. A notice appears with a **Use this shade** button that picks the nearest readable colour. You can also keep your own choice.

## Which designs use it

Designs 3 to 8 follow your colour. Classic and Modern keep their fixed look so existing invoices do not change.
