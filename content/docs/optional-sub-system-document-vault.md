# Optional Module: Document Vault

Document Vault centralizes business evidence and links files to ERP records.

## Enable from Settings

1. Open **Settings → Workspace Modules**
2. Toggle **Document Vault** ON

<HelpImage src="/help/diagrams/erp_entrypoint.svg" alt="Document Vault module toggle in settings" caption="Screenshot target: Document Vault card enabled in Settings." />

---

## What you can do

- Upload and triage docs
- OCR extraction and review
- Link documents to invoices/expenses
- Track storage usage
