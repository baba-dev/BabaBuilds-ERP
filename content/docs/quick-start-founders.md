# Quick Start for Founders (First 60 Minutes)

Short on time? Follow this path to go live quickly.

## Minute 0-15: Business setup

- Start from the plan-aware URL: `/signup?plan=pro&cycle=monthly&trial=15`
- Pick your onboarding persona (CA, Agency, Freelancer, Contractor)
- Complete Settings profile
- Add tax IDs and bank details
- Upload logo

## Minute 15-30: Revenue basics

- Add 3-5 clients
- Add top service offerings
- Create first invoice draft

## Minute 30-45: Collections readiness

- Enable Stripe/Razorpay
- Send one test invoice to yourself
- Verify payment link behavior

## Minute 45-60: Scale controls

- Enable Document Vault + Reporting Center
- Invite one ops owner
- Decide weekly finance review time
