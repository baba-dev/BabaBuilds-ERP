# Personalized Onboarding by Persona

BabaBuilds ERP now supports persona-aware onboarding paths so your first actions match your business model.

## Choose your persona

On first dashboard load, select one of:

- CA / Accountant
- Agency
- Freelancer
- Contractor

Each persona has dedicated onboarding steps and tailored recommendations.

## Persona money-task outcomes

Every flow ends with a completed money task:

- CA: send GST-ready invoice + verify filing readiness.
- Agency: set up a monthly retainer + bill first retainer invoice.
- Freelancer: send proposal + convert to invoice + send first invoice.
- Contractor: create milestone proposal + send milestone invoice + log first expense.

## Where to see progress

- Sidebar: **Start Here** checklist with progress and step tooltips.
- Dashboard first look: persona-tailored welcome copy and recommended actions.

## Update persona later

If your operating model changes, you can re-run onboarding and select a different persona path.
