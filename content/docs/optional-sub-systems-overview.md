# Optional Sub Systems — Overview

BabaBuilds ERP includes advanced modules you can turn on from **Settings → Workspace Modules**.

<Callout type="info">
  These modules are optional and non-destructive. Disabling hides functionality but preserves existing data.
</Callout>

## Where to enable modules

1. Open **Settings**
2. Scroll to **Workspace Modules**
3. Toggle a module ON
4. Save/confirm enable action

<HelpImage src="/help/diagrams/erp_entrypoint.svg" alt="Path to access settings where optional subsystems are enabled" caption="Enable advanced modules from the Workspace Modules section in Settings." />

## Available optional modules

| Module | Primary value | Recommended stage |
|---|---|---|
| Workforce | HR base records and attendance | Growing teams |
| Payroll | Salary runs and payroll controls | Teams with payroll cycles |
| Revenue Pipeline | Proposal stage visibility | Active sales motion |
| Document Vault | OCR and evidence storage | Compliance-heavy workflows |
| Cash Flow | Forecasting and liquidity insights | Finance maturity scaling |
| AR Aging + Collections Centre | Receivable recovery workflow | Credit-heavy billing |
| Reporting Center | Structured analytics and exports | Leadership reporting |
| Import Manager | Bulk data migrations and updates | Setup and expansion phases |

## Troubleshooting

| Problem | Likely reason | Fix |
|---|---|---|
| Module card is not visible | Insufficient permissions | Ask workspace admin to enable/manage settings |
| Module enabled but page unavailable | Navigation/session not refreshed | Refresh app and re-open module page |
| Team confusion after enabling module | No rollout SOP | Share module-specific article and setup checklist |
