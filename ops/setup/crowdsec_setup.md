# CrowdSec Setup Guide for BabaBuilds ERP

This guide helps you set up CrowdSec on your VPS to protect the ERP.

## 1. Install CrowdSec

Run the following commands on your Ubuntu/Debian VPS:

```bash
curl -s https://install.crowdsec.net | sudo sh
sudo apt-get update
sudo apt-get install crowdsec
```

## 2. Install the Nginx Collection

CrowdSec needs to know how to read Nginx logs:

```bash
sudo cscli collections install crowdsecurity/nginx
sudo systemctl reload crowdsec
```

## 3. Create a Custom Bouncer for the ERP

Since we handle blocking within the Next.js Middleware (`proxy.ts`), we need an API key for our "Bouncer":

```bash
sudo cscli bouncers add erp-nextjs-bouncer
```

**Copy the API key** generated by this command.

## 4. Configure the ERP

Update your `.env` file on the VPS with the API key:

```env
CROWDSEC_BOUNCER_KEY="<YOUR_COPIED_KEY>"
CROWDSEC_LAPI_URL="http://127.0.0.1:8080"
```

## 5. (Optional) Install Nginx Remediation Bouncer

If you want Nginx to block IPs before they even reach the ERP:

```bash
sudo apt-get install crowdsec-nginx-bouncer
```

## Verification

Check if CrowdSec is running:
```bash
sudo cscli status
```

List active decisions (bans):
```bash
sudo cscli decisions list
```
